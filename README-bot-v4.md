# V4 — 조용한 확인, 오빠 말투, 아침 계획 알림, 건강 기록

## 적용

1. V3가 적용된 Supabase 프로젝트에서 **`supabase/daddy_bob_jooseyo_v4.sql` 전체**를 실행합니다. 기존 데이터는 유지하고 `daddy_bob_jooseyo_` 객체만 추가·변경합니다. V2/V3 설치 SQL을 다시 실행하지 않습니다.
2. **`n8n/daddy-bob-jooseyo-v4.json`**을 새 워크플로우로 가져옵니다. 기존 Supabase, Telegram, 기본 Google Gemini 자격 증명을 선택합니다. `Get chat context`, `Get reminders`, `Process command`, `Mark delivered`는 V4 RPC를 호출합니다.
3. 이전 봇·알림 워크플로우를 Unpublish하고 V4 하나만 Publish합니다. API 키·아이디를 채팅이나 파일에 복사하지 않습니다. 기존 개인 계정 제한은 유지됩니다.
4. `/help` → 실제 수유 입력 → `웅` → `/history 별이`로 확인합니다. 의료 기록도 실제 관찰·투약 내용만 입력하세요. 아직 운영 DB나 n8n에는 자동 적용하지 않았습니다.

## 짧은 답과 알림 수 줄이기

- `응`, `웅`, `ㅇㅇ`, `넹`, `네!`, `응ㅋㅋ` 등 명시된 짧은 긍정과 `아니`, `아뇨`, `아닝`, `ㄴㄴ` 등 부정을 로컬 처리합니다. 무제한 유사 문자열/편집 거리 추측은 하지 않습니다.
- 대기 중인 현재 확인 토큰에만 동의/취소를 적용하며, 성공 후 같은 짧은 답을 다시 보내도 추가 저장·답장은 하지 않습니다. 같은 update_id 재전달도 조용히 무시합니다.
- `응 근데 100으로 바꿔`는 긍정으로 처리하지 않고 모델이 새로운 수정 내용을 해석합니다.
- 같은 수유 제안을 대기 중에 반복하면 확인 카드·토큰을 새로 만들지 않습니다. 기존 카드를 사용하세요.
- 모호한 답의 재질문은 같은 대기 요청당 최대 1회, 그 밖에는 2분 간격을 둡니다. 중요한 의료 경고는 확인/저장 응답에 표시합니다.
- 수유량 입력을 기다리는 중 `응`만 보내면 양을 만들어 저장하지 않습니다. `아니`는 그 입력을 취소합니다. `/help`나 확인 버튼은 계속 사용할 수 있습니다.

## 말투

`오빠, 별이 ... 이대로 남겨둘까?`, `오빠, 별이 120ml 기록해뒀어.`처럼 짧고 편안한 반말과 존댓말을 섞습니다. 실제 배우자라고 주장하지 않습니다. 숫자·약명·기록 시각·의료 경고는 스타일 변환으로 변경하지 않습니다.

## 아침 8~9시 계획 알림

- 모든 활성 아이에 기본으로 켜지며 기본 계획은 **사용자가 지정한 200ml**입니다. 보편적 권장량이나 의학적 처방이 아닙니다.
- 한국 시간 오전 **8:00 전용 스케줄**과 **15분 정기 스케줄**이 있습니다. 오전 8시 이상 9시 미만에 그날 전송하지 않은 아침 알림을 보내고, 실패하면 다음 정기 실행에서 재시도합니다.
- 발송 대상을 10분간 예약해 두 스케줄이 동시에 아침 알림을 보내지 않도록 합니다. 성공 전송 후에만 발송 날짜를 기록합니다. 아침 구간의 일반 수유 간격 알림은 생략합니다.
- 서버·네트워크·Telegram 장애로 전달을 절대 보장할 수는 없습니다. 전송 성공 직후 완료 표시가 실패하면 재시도에서 중복될 수 있습니다. 9시까지 전부 실패한 경우 이후 자동으로 몰아서 보내지 않습니다. n8n 실패 실행 모니터링이 필요합니다.
- 야간 알림 휴식과 별개인 사용자의 명시적 아침 알림 계획입니다. 자동으로 먹인 기록을 만들지 않으며, 이미 먹였다면 추가로 먹이지 말고 실제 먹은 양을 남기도록 안내합니다.
- `/morning 별이 180` 또는 “별이 아침 계획 180으로 바꿔줘” → 확인 후 변경. `/morning 별이 off` → 확인 후 끄기. 기본 발송 창은 08:00~09:00입니다.

## 건강·특이사항

| 입력 예시 | 처리 |
|---|---|
| `별이 체온 38.2도야` 또는 `/temp 별이 38.2` | 실제 측정 체온 확인 후 기록 |
| `별이 약이름 2.5ml 줬어` 또는 `/medicine 별이 약이름 2.5 ml` | 실제 약명·투여량·단위·시각 확인 후 기록 |
| `별이 오늘 기침 두 번 했어` 또는 `/note 별이 기침 두 번` | 관찰 메모 확인 후 기록 |
| `별이 특이사항 보여줘` 또는 `/health 별이` | 최근 10건, 한국 시간 조회 |

약 이름·양·단위를 추측하지 않습니다. 투약량 계산·다음 투여 권고·진단은 하지 않습니다. 시각을 지정하면 그 시각을, 생략하면 확인 요청 시각을 저장합니다. 미래나 출생 전 시각은 거절합니다. `health` 테이블에는 약명·실제 투여량·단위, 체온, 관찰 메모가 종류별로 저장됩니다.

생후 3개월 미만의 38℃ 이상 체온, 또는 40℃ 이상으로 입력되면 즉시 의료진 연락 안내를 표시합니다. 이 두 조건만으로 안전 여부를 판정하지 않으며, 다른 나이/증상에 경고가 없다고 안전하다는 뜻은 아닙니다. 처짐·호흡 이상 등 우려 증상이 있으면 의료진에게 확인하세요. 숫자를 모르는 “열이 나는 것 같아”는 관찰 메모로 남길 수 있지만 측정값을 지어내지 않습니다.

`/reset 아이`는 수유 기록만 삭제하며 건강 기록은 유지합니다. `/childdelete 아이`는 확인 후 해당 아이와 연결된 건강 기록도 삭제합니다. 기존 Telegram 대화, n8n 이력, 백업은 별도입니다.

## 검증

`npm run build:bot && npm run check && npm test`.

임시 PostgreSQL 호환 DB 및 모의 Gemini 응답으로 확인·취소·중복·스팸 방지, 정확한 체온/투약량/시각 보존, 아침 발송 예약·완료·재시도, 개인 계정·RLS·삭제 범위를 검증합니다. 운영 Gemini·Telegram 호출과 실제 다음 날 08시 스케줄은 게시 후 확인해야 합니다.
