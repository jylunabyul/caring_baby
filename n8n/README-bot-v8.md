# V8 하루 전체 타임라인

기존 V7 설치에 추가합니다. 기존 아이 프로필·수유·건강·성장·수면 기록은 유지합니다.

1. Supabase SQL Editor에서 `supabase/daddy_bob_jooseyo_v8.sql`을 실행합니다. V7이 먼저 설치되어 있어야 합니다.
2. `daddy-bob-jooseyo-v8.json`을 n8n에 가져오고 기존 Telegram / Supabase / Google Gemini 자격증명을 선택합니다.
3. 기존 봇 워크플로의 게시를 해제하고 V8을 게시합니다. 같은 봇에 활성 Telegram Trigger는 하나만 둡니다.
4. Telegram에서 `오늘 하루 기록을 보여줘`로 확인합니다. 자동 테스트는 로컬에서만 수행했으며 실제 서버 게시 및 Telegram 발송은 별도 확인이 필요합니다.

예시:
- `오늘 하루 기록을 보여줘` / `어늘 하루 기록 보여줘`: 모든 아이의 오늘 기록
- `별이 오늘 하루 기록 보여줘`: 별이의 오늘 기록
- `어제 하루 기록 보여줘`: 한국 시간 어제 기록
- `/timeline 2026-11-26`: 지정한 날짜의 모든 아이 기록

한국 시간 00:00 이상, 다음 날 00:00 미만에 해당하는 실제 수유·체온·투약·메모·수면·성장을 시간순으로 표시합니다. 늦게 입력한 기록도 실제 발생 시각에 들어갑니다. 성장 기록에는 측정 시각 필드가 없어 등록 시각을 명시하고, 등록일과 측정일이 다르면 `시각 미입력`으로 표시합니다. 전날부터 이어진 수면은 자정의 이어짐과 해당 일의 기상을 표시합니다. 예정된 투약 알림은 실제 투약으로 표시하지 않습니다.

최근 10건 제한이 없고, 긴 내용은 여러 Telegram 메시지로 나눠 전부 보냅니다. 요약에는 수유 횟수와 총 섭취량이 포함됩니다. 재고 변경 이력은 별도 저장되어 있지 않아 타임라인에 포함되지 않습니다.

변경 노드: Build Gemini request, Resolve short replies, Validate Gemini intent, Format response 및 RPC URL을 사용하는 HTTP Request 노드. 새 RPC는 `daddy_bob_jooseyo_bot_v8`이며 나머지 동작은 V7로 위임합니다. V7의 단축 명령 삽입 위치도 수정하여 정상 문맥이 오류 응답으로 조기 반환되지 않도록 했습니다.
