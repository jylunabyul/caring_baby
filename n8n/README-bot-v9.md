# V9 매일 오후 9시 정기 리포트

V8 SQL을 설치한 환경에서 사용합니다. 추가 SQL은 필요하지 않으며 기존 기록은 변경하지 않습니다.

`daddy-bob-jooseyo-v9.json`을 가져와 Telegram·Supabase·Gemini 자격증명을 선택하고, 기존 봇 워크플로를 게시 해제한 뒤 V9을 게시하세요. 같은 봇을 사용하는 Telegram Trigger가 동시에 여러 개 활성화되지 않도록 합니다.

- 워크플로 시간대: Asia/Seoul
- Daily report at 21 Seoul: `0 21 * * *` (매일 한국 시간 오후 9시)
- Prepare daily report: 실행 시각을 한국 날짜로 변환하고 고정 소유자 9114513581로 daily_timeline 조회
- Get daily report: 기존 V8 RPC로 모든 아이의 해당 날짜 전체 기록 조회
- Format daily report → Send daily report: 모든 페이지 전송. 기록이 없는 날에도 결과 전송

수유·체온·실제 투약·메모·수면·성장 기록을 시간순으로 보냅니다. 리포트는 오후 9시 발송 시점까지 저장된 당일 기록입니다. 오후 9시 이후 기록 및 나중에 추가한 기록은 자동 재발송하지 않으며 `오늘 하루 기록 보여줘`로 다시 조회할 수 있습니다. 수유 야간 알림 제한과 별개로 실행되며 예정된 투약을 실제 기록으로 만들지 않습니다.

새 Gemini 호출이나 데이터 쓰기를 추가하지 않습니다. 로컬 검증을 완료했으며 실제 발송은 n8n 게시 후 확인해야 합니다. 일시적인 서버 중단 중 놓친 스케줄을 자동으로 보충하는 기능은 없습니다.
